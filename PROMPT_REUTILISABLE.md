# Prompt premium pour créer un site d'évaluation interactive à partir d'un cours

Agis comme une équipe universitaire interdisciplinaire réunissant enseignant-chercheur Big Data, ingénieur pédagogique, UX designer et développeur full-stack.

Analyse intégralement le cours PDF joint. Conserve fidèlement ses notions, exemples, progression et limites ; n'évalue pas comme acquis un concept qui ne figure pas dans les pages étudiées.

Crée un site complet frontend + backend, déployable à partir de GitHub, pour une évaluation formative de **30 minutes**, notée sur **20 points**, destinée à **Licence IoT 1 GLSI — ISIMA — Université de Monastir — Module Big Data**. Utilise les logos fournis et la signature **Dr. Ing. Takwa BEN AÏCHA GADER**.

Pédagogie : varie QCM simples, QCM multiples, réponses courtes, justifications et exercices de code. Organise-les en compétences progressives, avec contextes réalistes et illustrations utiles. Pour chaque question, prévoit une consigne non ambiguë, un indice facultatif, un barème, un corrigé explicatif et une note partielle si un exercice comporte plusieurs critères.

Fonctionnalités : accueil soigné, progression, minuteur, navigation, correction immédiate sur place via backend, résultats détaillés, export individuel et reprise après actualisation. Les bonnes réponses doivent résider côté serveur, non dans le JavaScript envoyé au navigateur. Signale les limites de la notation automatique des textes.

Design : direction artistique académique originale, sobre et humanisée, grille typographique lisible, palette institutionnelle, responsive, mobile accessible, illustrations haute définition et diagrammes vectoriels scientifiquement exacts.

Livrables : code complet et organisé, images et SVG, tests automatisés, README GitHub et guide de déploiement d'une application frontend/backend (ne pas prétendre que GitHub Pages héberge un backend). Vérifie les parcours et livre un ZIP intégral prêt à déposer dans un dépôt GitHub.
